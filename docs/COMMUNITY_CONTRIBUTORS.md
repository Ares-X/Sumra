# Community contributors

The four README contributor sections are generated by
`scripts/update-community-contributors.py` from GitHub activity, including
historical activity. The rest of each README is preserved.

## Recognition rules

- Issue authors qualify when an issue has at least one of `bug`, `enhancement`,
  `documentation`, or `community-credit`. Both open and closed issues qualify.
- Authors of merged pull requests qualify. Unmerged pull requests do not.
- Reviewers qualify once per merged pull request when they have an `APPROVED` or
  `CHANGES_REQUESTED` review. Comment-only, pending and dismissed reviews do not
  qualify. Authors do not receive review credit for their own pull requests.
- The maintainer (`Ares-X`) and GitHub bot accounts are excluded.
- `invalid`, `duplicate`, `spam`, `wontfix`, or `no-credit` excludes the entire
  issue or pull request, including its reviews.

Ordinary discussion comments are not automatically credited. Maintainers can
use `community-credit` to recognize a qualifying issue report or `no-credit` to
exclude a record. Contributions are grouped by account and sorted by total
contribution count, then by account name.

## Updates

The workflow refreshes the list on issue events, merged pull request closure or
label changes, daily at 03:23 UTC, and manual dispatch. Reviews are collected at
merge; later review changes are reconciled by the daily or manual run.

Pull request checks run with read-only access. The updater uses only code from
`main`, including for fork contributions via `pull_request_target`; it never
executes a pull request head with write access. Its token has `contents: write`,
`issues: read`, and `pull-requests: read`. It commits only changed README files.
Repository rules must permit these bot pushes to `main`; a rejected push fails
the run and remains visible in its logs.

## Local validation

```sh
python3 -B -m unittest discover -s tests -p 'test_community_contributors.py' -v
```

The tests use offline fixtures and temporary README copies; no token is needed.
