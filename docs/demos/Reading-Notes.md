# A little room for reading

*Field notes · A Sumra demo document*

A document, a quiet window, and the next page. Reading should feel that simple.

## 1. Find your place

Some days call for a technical paper. Others call for a novel, a notebook, or a few pages of a comic. Keep the tools close and the document closer.

> A good reader gives the page room to breathe.

Use the contents sidebar to move between chapters. Search a title, follow a passage, or leave a bookmark for tomorrow.

## 2. Make the page yours

Change the type size and let the text flow into its new shape. Try a wider margin, a gentler line height, or a two-page spread.

| A small habit | A quieter desk |
| :--- | :--- |
| Read one page at a time | Keep your place |
| Mark a useful passage | Return when you need it |
| Open the file you have | Spend less time organizing |

### A note in two languages

阅读不必复杂。一份文档，一个安静的窗口，下一页就在眼前。

Keep the words clear, the controls familiar, and the distance to the next chapter short.

## 3. Work with your documents

A PDF can be more than a picture of a page. Select its text, fill a form, add a note, or save a copy for someone else.

Markdown can stay a notebook. A long document can become a book of pages. A web page can keep its style while you read, then flow into a PDF when you export.

```swift
let reading = Document.open("a-good-page.pdf")
reading.bookmark("Come back here")
```

*This code is illustrative demo text, not a Sumra API.*

## 4. Leave a little space

There is no account to create and no library to maintain. Open a file from Finder, drop it into the window, and start reading.

### One last page

Put a bookmark here. Close the window when you are done. The words will wait.
