# Sumatra UI feature inventory

This inventory maps implemented graphical commands to their owner. AppKit
supplies the macOS controls and dialogs. Current status and the finite work
queue are in [the work list](RELEASE_CHECKLIST.md); entries below identify where
behavior lives, rather than requiring every possible scenario before release.

| UI area | Sumra route and owner | Remaining check |
| --- | --- | --- |
| Open, recent files, windows/tabs | Finder/Open/drop, recent and saved groups, duplicate/merge/detach in `SumraApp.swift`, `ReaderState.swift` and app callbacks. Home has a 560 × 500-point minimum and centered content capped at 760 points; document windows retain a 560 × 400 minimum. Launch Services prohibits duplicate application instances while one process can own multiple document windows. | Current-build Finder, restoration and multi-window focus/close behavior. 857 covered Home minimum/maximized sizes and light/dark appearance. |
| Browse, history, bookmarks | File browser, previous/next history, named bookmarks and Bookmarks Window share reader state. | Keyboard/accessibility order, stale/missing files and cross-window persistence. |
| Layout and zoom | Fixed pages use translated row/spread geometry, 8.33–6400% levels, actual/fit modes, continuous/paged, cover, RTL, rotation and presentation. Text/reflow settings use native/MuPDF owners. Browser Markdown zoom multiplies the base font size while retaining normal image and viewport scale; tests preserve passage and selection through text-size changes. HTML/CHM retain whole-page zoom. | Broader authored-style reflow and process relaunch, extreme browser tail, physical trackpad and frame-time. Earlier bounded local checks covered ordinary Markdown window reflow and restoration; integrated candidate evidence is summarized in the [current work list](RELEASE_CHECKLIST.md). |
| Navigation and search | Page/line/chapter jumps, contents, thumbnails, Search results, Find options and previous/next; command palette prefixes select tabs/history/bookmarks/contents/pages/annotations/settings. Loaded 699 passes all seven selected inline-SVG words at 150%, with continued/wrapped Find and complete aligned paint. Loaded 696 retained the actual near-end Markdown passage through sidebar open/close; the unchanged resource remains covered by current resize tests. Earlier loaded 685 100% Markdown 143-result search and cross-file/query-replacement observations retain their historical scope. | Giant-document narrow 150% true tail, broader selection/accessibility, multi-format exact text and search latency. Earlier bounded local checks covered ordinary Markdown selection and window restoration; integrated candidate evidence is summarized in the [current work list](RELEASE_CHECKLIST.md). |
| Contents and bookmarks | Native title search preserves matching ancestors and original destinations, pauses automatic follow-current expansion while filtering, and restores collapsed branches on clear. Hierarchy collapse/expand/follow-current, keyboard navigation, page previews and persistent locations in `ReaderAids.swift` and reader state. Markdown/HTML headings load on Contents or palette demand; bounded visible recovery and palette navigation passed on the preceding 679-test candidate. | Malformed outlines, real IME/VoiceOver, broader native focus transitions and relaunch. |
| Selection, speech and images | Copy text/page or selected image, reading aloud with controls, screenshot and image save/crop/resize. Browser speech and range text resolve passage endpoints once, avoiding repeated distant-position checks for large selections or cursor continuation; word highlighting uses binary lookup over existing UTF-16 offsets. Silent tests preserve exact text, selection and cross-node word ranges. | Real audio and cross-page selection, image output fidelity and chosen external-service behavior. |
| PDF forms/annotations/tools | Editing lock, AppKit field controls, MuPDF actions/journal, annotation placement/properties and separate-output PDF Tools. | Full forms/annotations/permissions/signatures matrix and exact reopen checks on current build. |
| Printing | macOS print panel and document-specific print routes. Browser documents capture current forms, loaded frames and print media into a MuPDF snapshot; actual 855 GUI Export PDF and Print → Save as PDF passed. | MuPDF layout may differ from the browser view. Physical printer output and broader device-specific behavior remain unverified; final-app failure prompts retain their separate boundary. |
| Themes, settings, help | Appearance, palettes, language choices, shortcut editor, custom commands/toolbar, local help and Sparkle update surface. | Translation completeness, visible-window/accessibility checks and signed update delivery. |
| AI and source synchronization | User-triggered external AI CLIs, browser translation/search and inverse PDFSync/SyncTeX editor launch. | Installed provider responses, privacy/UI handoff and external editor workflow. |

Windows shell/default-app registration, Win32 dialogs, DDE and CLI/silent printing are platform-specific or excluded by the GUI product decision. An upstream enum value alone is not evidence that a UI command is reachable. Detailed decoder and PDF feature subsets are in [engine parity](SUMATRA_ENGINE_PARITY.md); source routes and test boundaries are in [implementation status](IMPLEMENTATION_STATUS.md).
