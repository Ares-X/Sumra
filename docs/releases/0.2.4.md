Sumra 0.2.4 reduces large Markdown opening and layout work, and improves PDF rendering.

- Markdown uses MuPDF's chapter model: index headings once, lay out the chapters being read, and retain their existing source positions. Continuous reading joins chapters without artificial page gaps; single and two-page modes paginate the current chapter.
- Whole-book Markdown searches process cold chapters without filling the reading cache. Cache size includes completed layout, and result counts remain correct when moving between matches.
- Finite reflow uses the available window frame for pagination, avoiding a feedback loop between fitted page size and scrollbars. Two-page reading prepares adjacent chapters before pairing pages, and source capture keeps stable chapter coordinates when page counts change.
- PDF display lists share MuPDF's bounded document store. Rendering replays immutable lists in cloned contexts, while edits invalidate the document's cached lists. Visible pages can promote an existing neighbor prediction instead of waiting behind background work.
- Window toolbars keep stable controls across document formats and window closure, fixing a toolbar synchronization crash found during original-book acceptance.

Local original-book checks reduced the 20.65 MB Markdown's load-to-first-canvas interval from 2.36 to 1.22 seconds. A separate fresh native first-image probe took 0.71 seconds with a 208 MB physical footprint; that probe is not a GUI measurement. The earlier 13.5-second event still lacks its original sampling evidence, and its unique cause remains unresolved.

Requires macOS 13 or later on Apple Silicon. Actual runtime checks use the available macOS 27 machine; macOS 13 runtime has not been exercised. The existing self-signed identity and Sparkle update key are retained. Corresponding source, provenance and checksums accompany the app.
