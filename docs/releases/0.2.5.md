Sumra 0.2.5 improves loading while scrolling into unread comic pages.

- Decode comic images outside the archive queue and reuse in-flight work between visible pages and prediction.
- Predict the next viewport in the reading direction, including short pages and spreads, using the existing bitmap memory budget.
- Preserve completed solid-7z entries and decompression progress when scrolling cancels an obsolete request.
- Reuse concurrent PDF bitmap requests and serialize replay of shared PDF image resources, following SumatraPDF's document ownership.
- Measure PDF content bounds per subpath so off-page crop marks do not prevent trimming empty margins.
- Preserve the selected EPUB search result when typography reflow interrupts Find with its panel closed.

First access to a distant page in a solid 7z archive still requires sequential decompression of its preceding entries.

Requires macOS 13 or later on Apple Silicon. Runtime acceptance uses the available macOS 27 machine. The existing self-signed identity and Sparkle update key are retained. Corresponding source, provenance and checksums accompany the app.
