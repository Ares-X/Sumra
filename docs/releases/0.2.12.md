# Sumra 0.2.12

- Keep shaped words intact when exporting EPUB, HTML and Markdown to PDF. Urdu, Bengali, Sinhala and other complex-script text can now be copied and found after reopening the exported file, without spurious spaces or line breaks inside words.
- Correct a shifted Odia outline in PDF exports when an installed AAT font uses a deleted-glyph marker.
- Include visible continuation outlines in search highlights when a character's text glyph has zero width.

This preserves the original text in the new PDF using standard ActualText metadata. It does not rewrite source books or recover missing word boundaries in older PDFs that lack that metadata.
