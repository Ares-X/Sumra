# Sumra 0.2.32

- Window-button hover state refreshes after window-size and fullscreen changes. The floating red window button closes the complete tab group from any selected tab, preserving save and cancellation prompts.
- Floating controls no longer add a second menu-bar gap on fullscreen displays that already exclude that area. Clicking a normal titlebar activates Sumra when another app was active.
- Always Hide collapses the native tab/titlebar accessory and keeps the document proxy hidden, while preserving native window buttons and restoring the prior tab-bar state when leaving the mode.
- Normal comic readers retain space for an automatically hidden progress slider. Scrollbar clearance follows the mounted reader and its final viewport size.
- EPUB covers share the facing page's paper geometry when Cover on Its Own is off, including Actual Size. Page images retain their aspect while replacement images render during resizing.
- Clicking a command or thumbnail row selects it on mouse-down and transfers arrow-key navigation to the list. Double-click and Return still activate the selection.
- Closed tab hosts no longer reconfigure themselves as welcome windows while AppKit finishes removing them from their group.

These changes address demonstrated failures from [issue #118](https://github.com/Ares-X/Sumra/issues/118). The report remains open for confirmation; local tab checks do not establish that every reported fullscreen Space transition is resolved.
