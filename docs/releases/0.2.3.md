Sumra 0.2.3 improves document opening and preserves reading positions across updates.

- Document opening, initial native preparation and visible-page rendering declare scoped user-requested activities, so macOS can finish them promptly even when another app is in front. Each activity ends when its task completes, fails or is cancelled; idle system sleep remains allowed. Neighbor predictions keep their background priority.
- Reading positions saved by 0.2.1 with the light theme restore through the update. Legacy finite-page EPUB bookmarks resolve their source before entering continuous flow.
- Changing reader colors preserves the exact text passage, including continuous Markdown while opening or closing Contents. Color-prefixed positions written by 0.2.2 normalize when reopened; source-file and actual user/publisher-style changes retain their existing identity checks.
- Home displays actual continuous reading progress for a single complete canvas and stable chapter progress for lazily laid-out EPUB books.
- Redundant MOBI repacking, repeated PDF information loading and unused internal reader adapters have been removed. Current-document PDF information, cached images and source restoration use their existing native owners.

Requires macOS 13 or later on Apple Silicon. Runtime acceptance uses the unchanged local books and records the signed candidate actually loaded; macOS 13 runtime remains unexercised on the available macOS 27 machine. This community build retains the existing self-signed identity and is not Apple-notarized. Corresponding source, provenance and checksums accompany the app.
