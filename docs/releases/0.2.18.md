# Sumra 0.2.18

- Keep link previews passive so links open with one click, preserve the pointer feedback, and keep previews within the screen. Remove destination circles from ebook navigation.
- Fix AZW3 table-of-contents links and CSS appearing as book text. Preserve large illustrations and their captions in FB2 and MOBI pagination.
- Add one **Toolbar Display** setting: **Always Show**, **Auto Hide**, or **Always Hide**, shared by Settings and the View menu. Auto Hide reveals controls near the window top and overlays them without moving or repaginating the book, including in full screen.
- Refine toolbar, reading-settings and selection-control transitions, with interruptible fades and support for Reduce Motion. Hidden toolbar space follows the reading theme. Full-screen controls use the native presentation policy so hidden chrome does not cover the first line and the wider hover region reveals controls onscreen.
- Correct comic thumbnail proportions and Finder/Quick Look handling for CBR, MOBI, FB2 and AZW3, keeping their original file extensions.
- Improve large-document search and complete match counting with incremental native scans, accurate result locations and responsive cancellation. Preserve the selected occurrence across reflow and show the correct results after query changes.
- Fix reading-state, color and navigation regressions found during the broader reader workflow checks.

Thanks to @HomeStarRunnerTron for the detailed examples and feedback in [#42](https://github.com/Ares-X/Sumra/issues/42).
