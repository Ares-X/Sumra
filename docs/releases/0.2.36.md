# Sumra 0.2.36

- PDF attachment lists open without decompressing every file. Opening or saving an attachment reads the selected item. The picker fits its contents and shows long filenames on hover.
- Renaming an edited PDF preserves pending edits for the next save. Exporting PDF pages as images preserves the chosen directory, including folder names containing `%d`.
- HTML printing and PDF export preserve percent-encoded binary images and reuse remote images captured by WebKit when available. Saving a print job retains searchable text in the order AppKit produces the pages, including repeated or reversed pages.
- Failed visible page tiles release their render requests. Reloading the document can render them again without repeatedly showing the same error during ordinary layout updates.
- Floating document tabs have larger close targets and show the full filename on hover. Finder comic previews keep the page number visible when a page fails and provide larger navigation buttons for returning to the previous page.
