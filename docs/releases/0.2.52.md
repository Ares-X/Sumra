# Vira Reader 0.2.52

- Opening a file from Finder at launch keeps the temporary Welcome window from appearing before the document. Opening several files at launch opens each of them.
- Floating Reading Controls show one set of window-button glyphs, including in Auto Hide and Always Hide.

See [#165](https://github.com/Ares-X/Vira-Reader/issues/165).

If Vira Reader is already installed, update with **Help → Check for Updates**.

The GitHub ZIP is self-signed and distributed without Apple notarization. If macOS blocks an official download you trust, open **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple’s instructions](https://support.apple.com/en-us/102445)

Apple Silicon · macOS 13 or later.
