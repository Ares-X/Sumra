# Sumra 0.2.41

- Keep the hidden native toolbar out of floating-control fullscreen transitions, preventing the temporary strip that clipped the tops of the controls. Switching back to the ordinary toolbar restores its visibility.
- Finish native tab selection after newly opened scenes have joined their group. Batch opening and Duplicate now use the same final selection sequence as restored tab groups.

The existing macOS 26.6.2 virtual machine passed fullscreen Home batch opening, first-tab selection and duplication, both native new-tab buttons, seven-tab automatic hiding and Mission Control checks. The reporter's macOS 15.7.5 Space behavior still needs confirmation, so #137 remains open. Ordinary native tab widths continue to expand after the pointer leaves; the same behavior occurs in a standalone AppKit application.

Finder preview buttons retain the successful page after a corrupt-image error and can return to the previous page. In the tested Finder host, arrow keys select neighboring files before reaching the preview extension; use its page buttons to navigate within the preview.
