# Sumra 0.2.45

- Add optional window diagnostics in Settings and Help. Recording stays enabled
  across restarts, supports marking the current problem, and exports a local ZIP
  for an issue report. Previous recordings remain until manually removed.
- Trace tab creation/duplication, placement and ready decisions, Home transitions,
  loading, controls, activation and full-screen/Space events without recording
  document names, paths, contents or keystrokes.
- Show logging/export failures and preserve earlier evidence. Recording is off
  by default; reports are not uploaded automatically.

This diagnostic facility does not establish a fix for the black Space behavior
or Finder preview arrow-key routing. Issues #137, #148 and #96 remain open.
