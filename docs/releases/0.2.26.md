# Sumra 0.2.26

Fix Quick Look navigation after a page cannot be rendered ([issue #96](https://github.com/Ares-X/Sumra/issues/96)).

- Keep the last successfully displayed page and its navigation position when a comic image cannot be decoded or a book page fails to render.
- Restore the previous and next buttons after the error, so buttons and arrow keys remain available for returning to a readable page. The error stays visible; damaged pages are not skipped automatically.

Distribution retains the existing community code signature and signed Sparkle updates. The release is not Apple-notarized.
