# Sumra 0.2.21

- Keep long-document previews responsive in continuous reading. Page thumbnails and internal-link previews render only the area shown in the preview instead of rasterizing an entire chapter. Link previews start at their destination; fixed pages retain their complete preview and viewer rotation.
- Reveal the current page when opening the thumbnail sidebar, and keep it visible when navigating to another page.
- Start a new forward or backward search at the current reading position in the compatible browser reader. Paged columns and right-to-left reading now use document order, including wraparound at the start and end.
- Preserve the relative physical sizes of mixed-size facing PDF pages when switching between paged and continuous layouts, including right-to-left reading.
- Finish closing every requested tab. Bulk close now waits for each native close decision and PDF save; canceling or a save failure stops the remaining batch.
- Let Undo and Redo from a floating Find results panel apply to its parent PDF. Editing the search text keeps native text Undo and Redo.
- Keep saved bookmarks attached to the original file when opening from the separate Bookmarks window, including when another file replaces its old pathname.
- Navigate TXT bookmarks in character order within a long wrapped paragraph, preserving the existing UTF-16 anchors and older line-only bookmarks.
- Keep lazy chapter progress reversible at chapter boundaries. Clicking the current chapter-ending position keeps the reading location and history, and a final one-page chapter stays at 100%.
- Clear a folder search when entering another folder or returning to Recents, so a parent-folder query cannot hide the child files. The active search editor follows the new context.
- Show and seek the actual scroll progress in native continuous books, including one long chapter. The footer updates separately from the reader surface; unread chapters retain approximate progress and saved passages keep their source position.

In a local 300-paragraph HTML/Markdown fixture, the unrotated thumbnail bitmap decreases from 4,178,304 to 61,440 bytes. A separate internal-link fixture decreases from 84,074,880 to 1,689,600 bytes. These are rendered-image allocations, not whole-process memory measurements or a first-open speed guarantee.

Distribution continues to use the existing community signature and Sparkle updates. Physical trackpad behavior, full-book search latency and coverless EPUB Finder-thumbnail selection retain their previously documented limitations.
