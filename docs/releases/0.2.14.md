# Sumra 0.2.14

- Open books directly from Finder when Sumra is closed, without needing a Dock click or leaving an empty Home tab in front of the book.
- Keep the system color picker connected when the selected color is clicked again, and support accessibility activation of color wells.
- Keep advanced margins and CSS with the current book when another document opens in the same window. The settings panel now shows the book's filename.
- Keep the basic margin slider and advanced values in sync, so applying CSS preserves your latest margin change. Press Return in the margins field to apply advanced settings.
- Display saved CSS correctly when the settings panel is reopened or the current book changes.
- Update an open reading-settings panel when the interface language changes, keeping its drafts. Keep fractional margins readable without wrapping the value label.
- Keep **System** and previously saved retired themes selected when applying an unchanged theme dialog. The five built-in presets remain unchanged.
- Open the visual theme chooser and document color editor directly from **Aa**.

The color-panel, EPUB cover and multilingual reading fixes from 0.2.13 are retained.
