# Sumra 0.2.25

Reader interaction and layout changes from [issue #82](https://github.com/Ares-X/Sumra/issues/82):

- Keep restored documents in their saved tab positions, close a tab without rebuilding its neighbors, and route new tabs and windows explicitly when using native full screen. The floating tab strip accepts clicks across each tab and horizontal scrolling over the strip. Revealing the macOS menu bar on a new floating fullscreen tab keeps the book clear of the native toolbar shadow.
- Keep Reading Settings reachable while an auto-hidden toolbar has focus. A PDF label that is empty or contains only whitespace displays its physical page number. In the normal footer, center the percentage, slider and page count together. A progress bar set to Always Show keeps its space beneath the document when the top toolbar hides.
- Fit facing pages within their own slots and keep cover art aligned with its neighbor while dragging the window edge. A standalone cover uses its own viewport. Apply reader margins to the FB2 root and to image-only EPUB pages without doubling the surrounding space.
- Track scrolling in TXT by position in the source text, so the thumb stays with the passage as TextKit lays out unfamiliar lines. Native scrollbar tracks leave room for overlaid reading controls.
- In Command Palette and Choose Page by Thumbnail, click to select, then double-click or press Return to activate. The thumbnail chooser marks the current page separately. Opening a document picker waits for the palette to dismiss. Text selections in input dialogs use contrasting system colors.

See the [issue verification notes](https://github.com/Ares-X/Sumra/blob/main/docs/ISSUE_82_ACCEPTANCE.md) for the books, interactions and limits of the checks.

Distribution retains the existing community code signature and signed Sparkle updates. The release is not Apple-notarized.
