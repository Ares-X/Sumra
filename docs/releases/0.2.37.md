# Sumra 0.2.37

- Rapid page navigation now processes each turn and its viewport together. Page numbers and reading progress no longer replay older destinations after a burst of arrow keys or Next/Previous commands.
- Queued navigation uses the destination page's dimensions before deciding whether the next arrow should pan or turn. Single pages, facing pages, right-to-left reading and preserved page offsets retain their navigation behavior.
- First Page, Last Page and page-number jumps follow the same input order. A page that fails to render reports its error and releases navigation so another page can be opened.
