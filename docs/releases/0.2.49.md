# Vira Reader 0.2.49

- Added a Vira Reader file icon for ebooks and comics in Finder when a cover thumbnail is unavailable or Finder displays a small icon. To associate a format after moving from Sumra, select the file in Finder and choose **Get Info → Open with → Vira Reader → Change All**. Repeat for each format you want Vira Reader to open. See [#165](https://github.com/Ares-X/Vira-Reader/issues/165).

Apple Silicon · macOS 13 or later. Distribution uses the project's existing self-signed, nonnotarized package and signed Sparkle updates.
