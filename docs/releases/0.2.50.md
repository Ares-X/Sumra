# Vira Reader 0.2.50

- Finder uses a folded-page icon with the Vira logo and format label for ebooks and comics when it displays a generic file icon. Cover thumbnails remain available.
- CBZ and other supported book and comic formats use the same document artwork in the reader's titlebar. The native document icon follows macOS hover behavior when the Normal toolbar is shown.

If Finder still shows a cached icon, select an affected file and choose **Get Info → Open with → Vira Reader → Change All**, then restart your Mac. See [#165](https://github.com/Ares-X/Vira-Reader/issues/165).

Apple Silicon · macOS 13 or later. Distribution uses the project's existing self-signed, nonnotarized package and signed Sparkle updates.
