# Sumra 0.2.23

- Remove the persistent blank strip above fixed-layout PDFs when the native toolbar hides. Keep reading geometry stable during toolbar hover and full-screen transitions.
- Repair native New Tab and tab-overview opening, cancellation and closing. Keep document titles clear of window controls, make the title area draggable, and add visible hover feedback to floating window buttons.
- Correct thumbnail ordering and row activation, saved tab-group replacement and restore behavior, and Welcome-menu actions.
- Separate document margins from the space reserved for reading controls. Apply numeric typography, margins and page-grid values reliably, and keep Contents and AI sidebars clear of the progress controls.
- Synchronize Up/Down scrolling across facing TXT pages. Turn pages in paged HTML and CHM while preserving normal input-field editing.
- Preserve cross-file Markdown link targets when switching from WebKit to the native reader.
- Defer whole-file PDF hashing on the clone path until validation needs it, and generate TXT previews from a complete text prefix rather than decoding the whole book.
- Mark a successful annotation paste as modified before removing its source. If source deletion fails, retain the destination changes and the original error.
- Preserve paragraph boundaries in Read Aloud and clear the final speech highlight.
- Read PDF metadata and bookmarks containing MuPDF's modified UTF-8 NUL correctly, including the reported 454-page document with 101 bookmarks.
- Improve document sharing through email applications that support attachments, and complete translations for the new controls.

Validation and the tested scope are recorded in the [acceptance report](https://github.com/Ares-X/Sumra/blob/main/docs/RELEASE_0_2_23_ACCEPTANCE_20261101.md). Issue #55 remains the continuous review index.

Distribution retains the existing community code signature and signed Sparkle updates. The release is not Apple-notarized.
