# Sumra 0.2.31

- Switching PDFs clears the previous document's annotation filters. Filters remain in place while editing annotations in the same document.
- Search Contents reveals the contents sidebar before moving keyboard focus into it. Narrow-window sidebar changes return focus to the document when the focused control becomes hidden.
- Find waits for input-method composition to finish before searching and cancels an older pending search while candidates are being composed.
- Closing Ask Document keeps the current document's conversation and session. An active request is cancelled, and any partial reply remains visible. New Conversation and changing documents still clear the conversation.
- Streaming replies follow the bottom only while you remain there. Scrolling back to earlier answers keeps your reading position until you return to the bottom or send another question.
- Reading Settings explains which controls affect the current document, all reading windows, or saved defaults. The apply-to-all control also remains available for PDF margins.
