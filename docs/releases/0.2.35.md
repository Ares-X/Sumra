# Sumra 0.2.35

- The welcome window's close, minimize and fullscreen buttons now hide in fullscreen, appear when the pointer reaches the top edge, and hide again when it leaves. Leaving fullscreen restores the normal window controls without shifting the welcome content.
- Documents opened together in fullscreen keep their native window controls after leaving fullscreen.
- Scrollbar tracks update when reading controls or the native tab bar change, without requiring a window resize. Always-visible native controls no longer add a second top clearance.
