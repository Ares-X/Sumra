# Sumra 0.2.15

- Focus interface language choices on 25 common language/region options, with translations for all managed interface labels and instructions.
- Keep older language preferences and exported settings readable: removed interface choices use the system-language fallback.
- Preserve separate top, right, bottom and left margin defaults when exporting and importing settings. Advanced Settings accepts the same 0–200 point margins as the reading controls.
- Reduce repeated language matching when the interface follows the system language. Manual language changes still take effect immediately.
- Keep the last partial spread at the end of HTML, compatible Markdown and CHM topics, so the next-page command can enter the following chapter in either reading direction.

Document reading and font support remain independent of the interface language list. Native-speaker translation corrections are welcome.
