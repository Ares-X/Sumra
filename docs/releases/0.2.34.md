# Sumra 0.2.34

- Native window edges and corners retain macOS resize behavior instead of starting a window move. Empty titlebar space remains draggable, including when the reader toolbar is hidden.
- Floating reading controls keep their normal top spacing in fullscreen, without a permanent blank band for the hidden system menu. Revealing the system menu does not move the book or its scrollbar.

These changes address the remaining window-edge and fullscreen-spacing follow-ups to [issue #118](https://github.com/Ares-X/Sumra/issues/118).
