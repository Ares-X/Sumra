# Sumra 0.2.13

- Find phrases that continue onto another page in PDF, DjVu and paginated EPUB, with highlights on each page. Japanese and Chinese phrases also stay searchable across line wraps.
- Change fonts, colors, spacing and layout live from the **Aa** reading-settings panel. Customize keyboard shortcuts and the toolbar, and use the selection toolbar for common text actions.
- Open PDF locations from an editor through the documented macOS SyncTeX URL workflow, including password-protected documents and recompiled files.
- Browse and filter a CHM book's keyword **Index**.
- Show EPUB and comic thumbnails and paged Quick Look previews in Finder through bundled extensions.
- Preserve reading associations when files are renamed or moved, and load background document tabs when selected.
- Improve PDF choice fields: multiple selections, duplicate export values, validation, calculations, saved appearances, undo and keyboard/accessibility controls use the same document state.
- Reduce unnecessary work during large Chinese EPUB searches, reuse decoded MOBI text, and bound retained extracted comic data with cancellation between decoder reads.

The cover, color-picker and multilingual PDF-export fixes from 0.2.10–0.2.12 are retained. Large-book full search counts and distant seeks in solid comic archives can still take time. Quick Look provider selection is managed by macOS; complete Acrobat JavaScript compatibility, physical printer output and all older macOS versions are not claimed.
