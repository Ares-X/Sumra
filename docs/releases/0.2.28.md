# Sumra 0.2.28

- Docked Find keeps the query field and its buttons together at the leading edge. The match count appears beside the buttons after you type. Only documents that support a page range need a second row.
- Ask Document clears a submitted question immediately and leaves your next draft in place while you wait. The conversation shows which CLI is responding. Codex can finish reconnecting after an interrupted stream, and cancellations and failures clear empty reply placeholders.
- The search sidebar explains how to start a search. Empty command palette, bookmark and annotation lists show a result message.
- Link annotation properties and the PDF signing form give the address, coordinates and signature details enough room to read and edit.
- The narrow Reading Settings panel keeps its numeric labels aligned and readable beside their sliders.
- Translation preferences keep the source and target language labels visible after you enter a language code.
