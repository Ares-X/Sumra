# Sumra 0.2.33

- The floating tab strip grows with the number of open documents and the space between the navigation and reading controls. Short groups stay compact; wider windows show more tabs.
- Overflowing tabs support ordinary mouse-wheel scrolling as well as horizontal gestures. The new-tab button stays reachable, and switching documents or resizing reveals the selected tab.
- Tab labels and close targets stay inside their floating surface when native window titlebars and tabs are present.

This release addresses the adaptive-tab follow-up to [issue #118](https://github.com/Ares-X/Sumra/issues/118). The separately reported top-right resize/drag mismatch and extra fullscreen top clearance remain under investigation.
