# Sumra 0.2.29

- Reopening Find runs the saved search with its page range. Multiple results on the same page now have separate numbers so you can tell them apart even when their snippets match.
- In a narrow window, the contents list and Ask Document share the available space. Switching between them keeps the question editor, Send and Close in reach. The toolbar overflow menu gives each action a name.
- Closing and reopening Ask Document keeps your draft and the CLI you selected for it. A different document starts with an empty draft. Model and reasoning settings are available from Models beside the CLI selector.
- Reading Settings explains how to adjust individual margins when a preset is selected.
- The progress slider keeps the chapter shown during a drag when background pagination finishes before you release it.
- Previous File and Next File work when macOS gives the same folder two different paths.
- Replacing a PDF attachment updates its default filename in the annotation list. A note you wrote is preserved. One Undo restores the previous attachment and title.
