Sumra 0.2.6 improves distant jumps in solid LZMA2 comic archives and removes
unnecessary Home work during window closing and view changes.

- Index independent LZMA2 dictionary-reset sections and decode from the nearest section before the requested page.
- Build section offsets lazily in memory through the existing archive owner, using the system libarchive decoder.
- Preserve complete page bytes, per-entry checksums, forward progress and independent image decoding across jumps and cancellation.
- Handle encoded 7z headers, entries spanning section boundaries, multiple folders, empty files and duplicate names.
- Stop retained closed reader scenes from mounting Home and generating covers after the native window closes; returning Home in an open window remains available.
- Refresh Home's catalog and pin aliases when history, pins or sorting change, without rereading system recent documents merely to switch between list and thumbnail views.
- Reuse completed Home covers in a reclaimable memory cache, with source/sibling-cover modification times and requested output dimensions identifying the cached image.

Original books are opened read-only. This adds no persistent image cache or extracted copy of the book. A first jump can still require decoding the preceding data within its selected section; archives without suitable independent sections keep their existing reading path.

Requires macOS 13 or later on Apple Silicon. The existing self-signed identity and Sparkle update key are retained. Corresponding source, provenance and checksums accompany the app.
