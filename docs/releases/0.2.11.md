# Sumra 0.2.11

- Fit declared EPUB covers to the reading page without stretching, extra blank pages or repeated image fragments. Covers resize and stay centered in single-page and two-page layouts.
- Keep oversized illustrations and their captions together when the book requests it, while retaining surrounding text and cover links.
- Add link color, precise RGB fields and an instant preview to Custom Document Colors. The system color panel closes when applying or dismissing the theme and document-color editors.
- Use the standard macOS color wells so switching between colors does not go through a separate swatch popover.
- Activate Finder file-open requests before waiting for the initial reader window.

Original books are not modified. This follows the reproducible examples shared in [issue #31](https://github.com/Ares-X/Sumra/issues/31); the issue remains open for the reporter’s confirmation.
