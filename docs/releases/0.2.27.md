# Sumra 0.2.27

Fix Find controls around hidden and floating reader toolbars.

- Keep the Find row below the window controls and toolbar so its input and buttons remain clickable when the toolbar appears on hover.
- Click either toolbar's Find button again to close Find. Press Escape to close an active Find session even when the PDF canvas or search results have focus, then return keyboard focus to the document.

Distribution retains the existing community code signature and signed Sparkle updates. The release is not Apple-notarized.
