# Sumra 0.2.16

- Center EPUB heading decorations and title images that use automatic margins or a sized inline image container.
- Respect explicit image heights and percentage heights with a real containing-block reference, instead of overriding every image to automatic height.
- Keep a publisher logo small when the book already identifies a different image as its cover.
- Prevent an illustration at a page boundary from appearing again on the adjacent page at certain window sizes.
- Fit unsized, image-only sequences to the page in paged reading, keeping their proportions and centering them. Explicitly sized images and mixed text with illustrations retain their authored layout; continuous reading keeps its natural-height flow.
- Keep the same illustration in view when switching between paged and continuous reading in image-only EPUB chapters, including repeated copies of the same image.
- Make Markdown chapter links reach their heading in paged reading as well as continuous reading.
- Include the file name when a document cannot be opened, while keeping the previous document available.

These changes follow the third set of reduced EPUB examples in issue #31. The issue remains open for feedback on the reporter's Mac.
