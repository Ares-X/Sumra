Sumra 0.2.2 improves reflow reading and large-document responsiveness across books, Markdown and plain text.

- Seamless continuous reading, Single Page and Two Pages preserve the source passage through mode changes and reopening.
- Returning from a later double-page passage keeps the outgoing page until continuous geometry and position are ready, preventing an intermediate whole-chapter render and blank viewport.
- Large Markdown reuses parsed layout and font metrics. Two original 14.17/20.65 MB books completed GUI mode layout in 0.40–0.63 seconds; their first chapter layouts took 0.94/1.92 seconds on an M3 Max. Mode handoff retains viewport tiles instead of allocating a whole-chapter bitmap.
- Directional neighbor rendering, bounded text extraction and search improve reading responsiveness. CHM prose adapts to the window and reader typography; redundant prose gaps are compacted without changing source text.
- Comic archive folders appear in Contents. Scanned PDF text receives automatic display contrast, with a per-document switch. The default reading background is light.
- Project build and release tooling uses Swift and system tools; the app has no Python dependency and ships as one complete bundle.

Validation: 854 reader/core tests and 58 packaging checks passed, followed by five focused continuous-reader checks covering the corrected mode handoff. Actual GUI workflows were exercised with the local book corpus, with both large Markdown books rechecked for opening, modes, search, Contents and fresh-process position restoration. All 25 original files remained unchanged.

Requires macOS 13 or later on Apple Silicon. Runtime was exercised on macOS 27.0.1; macOS 13 execution was not exercised. This community build retains the existing self-signed identity and is not Apple-notarized. Corresponding source, provenance and checksums accompany the app. Version 0.2.1 can update through Help → Check for Updates; 0.2.0 requires a manual installation.
