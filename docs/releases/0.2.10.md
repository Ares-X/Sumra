# Sumra 0.2.10

- Fix missing Hebrew glyphs with the default reading font, including bold and italic fallback.
- Load selected system variable-font weights faithfully in reading and exported PDFs, including Kefa III Bold on current macOS.
- Keep active Chinese/Japanese input composition intact when Find or Contents updates.
- Preserve combining marks and ligature letters in viewport copy and assistive reading text.
- Keep authored HTML words intact when glyph spacing would otherwise insert false spaces and break searches.
- Add core interface translations and distinguish a theme's name from the signature-name checkbox. Settings now marks partial translations and explains English fallback.

Language validation covers representative text, mixed direction, font styles,
search, export and native input composition. It is not a claim of complete
Unicode coverage or native-speaker review. See [language support](../LANGUAGE_SUPPORT.md).
