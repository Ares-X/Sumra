# Reader interactions and book layout in 0.2.25

The reporter verified these problems in 0.2.24 (26). The table pairs the reported actions with the observed behavior. App replays used a macOS 26.6.2 (25G83) virtual machine. Hosted checks used actual AppKit controls and rendering, with window input supplied by the test harness. [Original report](https://github.com/Ares-X/Sumra/issues/82)

The first signed candidate was built from `bba387ce`. Subsequent local Release runs used `349e8dd2`, then `0f3b7786` for command availability and PDF editing, and `c14ba3e4` for the original first spread and the native system language. A successful check on a later pair of pages did not cover the first spread. The C and E entries below identify which pair was visible.

One early native-tab replay recorded ignored mouse clicks. In fresh launches, independent mouse events selected each document and a surviving tab after a close. The virtual machine did not measure a physical trackpad's feel. The issue remains open for the reporter to test on their own system.

One earlier replay that switched from floating to normal controls before exiting fullscreen left a native transition window above the reader. Its first page-button click did not reach the document. Bringing the reader to the front restored input. Two independent cold starts of the integrated application repeated the sequence using mouse and keyboard events without a window-focusing automation utility. Both the second-tab and third-tab scenarios returned to the original 900 × 622 frame. The first physical Next click in each advanced the displayed EPUB. A normal-toolbar round trip also passed. The cause of the single earlier occurrence was not established.

## Release checks

The changes covered native tab and toolbar behavior, consecutive resizes, whitespace-only PDF labels, the fullscreen shadow and the misaligned first spread in the original C book. [PR #83](https://github.com/Ares-X/Sumra/pull/83) · [PR #84](https://github.com/Ares-X/Sumra/pull/84) · [PR #85](https://github.com/Ares-X/Sumra/pull/85) · [PR #89](https://github.com/Ares-X/Sumra/pull/89)

A community-signed candidate was built from `8afc84e8b502f03efeab09e7423779dc2ccf7228`. GitHub did not allocate a macOS 15 runner for the preceding attempt. The release used a standard Xcode 27 runner with a temporary workflow reference that changed only the runner label. The application checkout, signing identity, source pins and publication workflow remained those in the repository. [Candidate build](https://github.com/Ares-X/Sumra/actions/runs/41508799191)

The manifest SHA-256 for that candidate was `755327c6464688195902114b1a11b11c534562e1a5f6eb32b5e5a5c0c37c4698`. Verification covered 140 application files, five symbolic links, the existing signing certificate, both Quick Look extensions and the Sparkle update signature. The source archive contained 13,616 files and 17 symbolic links. All 593 project files matched their Git revision. Seven targeted original-book tests loaded the signed application's MuPDF library. In the signed application's first C spread, the artwork differed by at most one physical pixel across two held drags and release on the 2× display.

The full local suite on the release source ran 1,562 cases: 1,558 passed, none failed and four were skipped. Two skipped fixtures require manual window input, one requires the legacy scrollbar configuration and one checks title behavior on an older macOS version. The corpus included 25 books and 4,942 comic pages. All 44 original inputs retained their hashes, sizes and modification times.

A cold start from the signed bundle in Applications opened E, entered fullscreen and added C as a second tab. Moving the mouse to y=0 revealed the system menu without the stripe. After switching off floating controls and exiting fullscreen, the original reader was the focused native window. The first mouse click on Next changed the actual page field from 1:1 to 2:1 and painted the new page.

A separate launch restored PDF, E and TXT in their saved order. Each selected title matched its document. Closing the leftmost PDF kept the pointer over the strip. Clicking the remaining TXT there displayed its first section. Cmd-W left E on screen and Close and Quit then terminated the app.

The same signed candidate failed Move Tab Left in the restored three-file group. With E in the middle, moving it left changed the group’s window order but left the native strip labeled PDF, E, TXT. After the interface settled, clicking the left PDF label showed E and clicking the middle E label showed the Midnight PDF cover. This candidate was withheld from publication.

## Broader local workflows

- In a PDF whose publisher supplied whitespace for page labels, entering 2 and pressing Return showed physical page 2 in the body and the toolbar. Next displayed the following Roman label. Previous returned to the visible 2.
- In a three-page PDF the reader followed Contents and search results, edited a text form and a checkbox, undid and redid the text edit, and saved the original and a copy. An independent PDF reader reopened both saved files with the submitted values. Printing through the system PDF destination produced a readable three-page document.
- On a Mac configured for Simplified Chinese with Sumra set to System, the reader UI was Chinese but macOS displayed the earlier bundle’s Open, Save and Print panels in English. Sumra now registers its 25 bundled interface languages. The cold-started integrated app displayed its native Open panel in Simplified Chinese. Isolated AppKit checks also covered French, English and the English fallback. [System language correction](https://github.com/Ares-X/Sumra/pull/88)
- On Home the disabled Save and Save Copy commands now report their availability to accessibility clients. Searching for Save Copy and pressing Return left the palette open. Choosing Open with the keyboard produced the file panel. [Accessibility correction](https://github.com/Ares-X/Sumra/pull/86)
- The retained large EPUB returned all 100,144 whole-word search results at the recorded 779 × 590 reader layout. Comparing the package engine’s ordered source positions, chapters, page numbers, UTF-16 ranges and context offsets found no differences. The hosted reader also navigated to the last match, turned a page while a count was in progress and cleared old results when the query was replaced. [Hosted search test setup](https://github.com/Ares-X/Sumra/pull/87)
