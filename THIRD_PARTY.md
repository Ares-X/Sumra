# Source provenance and notices

Copyright (c) 2026 Sumra contributors. New Sumra code is licensed under AGPL-3.0-or-later; see [LICENSE](LICENSE). Earlier MIT code and its notice are retained below. This document identifies source use; it does not certify a completed binary redistribution audit.

Sumra translates selected SumatraPDF behavior and uses mature document libraries. It is not a clean-room implementation or a Win32 UI port. AppKit, CoreGraphics, ImageIO, WebKit and Security provide native macOS features. PDFKit is used only in tests to construct fixtures or independently inspect output. No Windows DLL or Windows renderer is bundled.

`Native/mupdf-snapshot.patch` modifies the pinned AGPL MuPDF `source/pdf/pdf-write.c` snapshot writer to retain the live document's source baseline, incremental sections and journal. New or already repaired documents use full snapshots through the same writer: mutating xref preprocessing is skipped, and compressed objects are emitted as ordinary generation-zero objects without altering the live xref. Form calculations and appearance updates are committed by the existing edit transaction. This is a local correction to MuPDF's snapshot implementation, applied by `build-engines.sh`; upstream acceptance is not claimed; local Debug regressions cover repeated classic/xref-stream snapshots, repaired encrypted ObjStm copies, failure recovery and retained undo/redo.
